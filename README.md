## Featured Work

### HajiriKhata — Attendance & Payroll System

> *Built for Eastern Auto Distributors Pvt. Ltd., a spare-parts distributor in Jhapa, Nepal. It runs attendance and salary for the company's employees every day.*

**Problem:** Attendance and salary were calculated by hand, with rules for late check-ins, lunch overruns, half-days, overtime and field tours. Mistakes were constant and disputes were hard to settle.
**Solution:** An employee mobile app for check-in and check-out plus viewing their own pay, a web admin dashboard, and a Node/Express API. All three share one payroll engine and a dual Nepali **BS / AD** calendar.
**Stack:** React Native (Expo) · React · Node.js / Express · Supabase (Postgres) · Render
**Role:** Sole developer (design, backend, mobile, web, deployment)

**Engineering highlights**
- **One source of truth for money.** I found a parallel ~250-line salary implementation that made the employee and admin views disagree. I deleted it and sent every pay view through a single `calculateSalary()` function.
- **Rule-based time engine.** Per-hour grace windows, lunch-overrun rounding, half-day detection and super-admin-only manual overtime, with 233 historical OT records kept intact through a schema migration.
- **WhatsApp notifications.** A Cloud API outbox table, a cron-driven queue with a deduplication guard and template messaging.
- **Printable payslips** for one employee or the whole team, for any date range.
